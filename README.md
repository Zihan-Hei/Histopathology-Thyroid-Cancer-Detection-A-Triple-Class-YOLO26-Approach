# Histopathology-Thyroid-Cancer-Detection-A-Triple-Class-YOLO26-Approach

**Overview**

This project investigates the application of YOLO26s for detecting and localizing thyroid cancer (TC), abnormal tissue, and normal tissue in histopathological images. To address class imbalance, the original nine tissue classes were consolidated into three categories, and hyperparameter tuning and data augmentation were incorporated to improve detection performance.

The optimized triple-class YOLO26s model achieved an overall mAP50 of 0.571, precision of 0.541, recall of 0.606, and mAP50–95 of 0.225 on the independent test set. Detection performance was highest for abnormal tissue (mAP50 = 0.770), while TC remained the most challenging class (mAP50 = 0.324).

The findings suggest potential for AI-assisted histopathological pre-screening, although further improvements and clinical validation are necessary before practical implementation.

**Project Goals**

Our goals for this study included:
1) Evaulate YOLO26's ability to detect thyroid cancer and abnormal tissue in histopathological images
2) Explore whether AI-assisted image anyalysis can support thyroid cancer diagnosis and reduce clinican workload

**Dataset**

The dataset used in this project comes from the [Roboflow Univerese repository](https://universe.roboflow.com/thesis-yczhj/thyroid-cancer-detection-j8r8b) and contains 533 annotated histopathology images of thyroid tissue with bounding box annotated histopathology images of thyroid tissue with bounding box annotations for object detection tasks.

The original dataset contained 9 classes:
- TC (thyroid cancer)
- Abnormal
- Fibrocollagenous Tissue
- Fibromuscular Tissue
- Inflamitory Cell
- Lymphoid
- Normal
- RBC (red blood cells)
- Stroma
To address class imbalance and improve model performance, biologically similar classes were merged into a simplified triple-class dataset.

Final classes included:
- TC = Malignant thyroid tissue
- Normal = Healthy thyroid tissue
- Abnormal = Non-cancerous but atypical tissue including inflammatory and fibrous components

The dataset was split:
- Training: 278 images
- Validation: 60 images
- Testing: 60 images

**Methods**

We employed the YOLO26s architecture (Ultralytics 26.0.0) to detect and localize thyroid histopathological tissue regions. 

YOLO26 was selected because of:
- Fast inference speed
- Real-time object detection capability
- Strong perfromance on image localization tasks
- Improved efficiency compared to earlier YOLO versions

Several classification strategies were investigated, including nine-class, five-class, binary, and three-class configurations.

The final three-class configuration consolidated the original tissue categories into thyroid cancer (TC), abnormal, and normal tissue. Model performance was assessed using precision, recall, mAP50, and mAP50–95.

**Data Preprocessing**

To determine the best classification structure, the mdoel was traine dunder several configuarations:
1) 9-class model
3) Binary model (TC vs Normal)
4) Triple-class model (TC, Abnormal, Normal)

The triple-class configuration produced the best overall detection performance and became the final model used in this study.

**Data Agumnetation**

To address class imbalance and improve representation of different tissue types, we applied standard image augmentation techniques, including mosaic augmentation, horizontal and vertical flipping, rotation, and HSV adjustments.

Additionally, 300 synthetic mixed-scene images were generated by combining tissue regions from TC, abnormal, and normal categories to expose the model to more diverse tissue contexts during training.

**Hyperparameter Tuning**

YOLO's built-in turning framework was used with:
- AdamW optimizer
- Cosine learning rate decay
- 20 tuning iterations
- Label smoothing
- Mosaic augmentation
- Rotation augmentation
  
The optimized triple-class YOLO26s model was trained for 100 epochs with an image resolution of 640 × 640 pixels and a batch size of 16.

**Key Findings**

- The optimized triple-class YOLO26s model achieved an overall mAP50 of 0.571 and recall of 0.606 on the independent test set
- Abnormal tissue demonstrated the strongest detection performance, with an mAP50 of 0.770 and recall of 0.826
- Dataset imbalance significantly affected TC accuracy, with an mAP50 of 0.324 and recall of 0.357
- AI-based pathology tools may be useful as **pre-screenign assistants** rather than standalone diagnostic systems

**Limitations**

- Small satset size
- Severe class imbalance
- Only four test images contained TC annotations, limiting confidence in the stability of class-specific performance estimates
- TC recall of 0.357 indicates that a substantial proportion of annotated thyroid cancer regions were not detected at the evaluated operating point
- Inconsistent image magnification across classes
- The model was evaluated on a research dataset and has not been established as safe or reliable for independent clinical diagnosis

Because of these limitations, the model is **not suitable for standalone clinical diagnosis**

**Conclusion**

The optimized triple-class YOLO26s model demonstrated the potential of deep learning for detecting and localizing thyroid histopathological tissue regions. 
The model achieved an overall mAP50 of 0.571 and recall of 0.606, with the strongest performance observed for abnormal tissue.

YOLO26 demonstrates potential as a supportive AI tool for thyroid histopathology analysis. While the model is not accurate enough to replace pathologists, it may help:
- Identify abnormal tissue regions
- Prioritize cases for review
- Improve workflow efficiency in clinical settings

Future work should focus on:
- Expanding malignant tissue representation
- Improving class balance
- Training on larger histopathological datsets
- Validating performance on independent clinical datasets
